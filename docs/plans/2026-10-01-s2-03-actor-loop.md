Notes:

- **Waves.** 1 to 7 run at once (disjoint files). 8 and 9 follow, side by side. Then 10, then 11, then 12. No step changes `pnpm-lock.yaml`; no new dependency.
- **The barrel.** Only step 11 edits `packages/agent/src/index.ts` (three lines: `actor-backend`, `actor-loop`, `llm-actor`), so parallel steps never touch it. Tests import modules by their relative path.
- **Step 7** is pure plus types: `performAction` needs a live page and the navigation watch is exercised end to end in step 10 (every click, the scroll, the back), so it gets no browser test of its own.
- **Step 10's tests** answer by element name through a test-local `refFor(request, role, name)` that reads the turn message. Missing refs are the literals `e99` and `e98`. The masked-name loop test finds its seed with `perceive(measurementFixture, vera, seed)` for the "Order archive" key. Caps are 2 or 3; no `wait` answers.
- **Step 11's manual check** without a key must not reach a model: `parseLlmSettings` fails at boot, naming `LLM_API_KEY`.
- **Step 12, the real key.** The worktree has no `.env`. The user provides the key for the one real run (the root `.env` of the worktree, gitignored), or runs the command themselves.
