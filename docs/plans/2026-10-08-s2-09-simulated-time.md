Notes:

- **Order.** Step 1 commits before any code, as the task asks. Step 2 lands next, since 3 to 6 read its types. Then 3, 5 and 6 run in parallel, and 4 after 3. Their files are disjoint, and none touches `pnpm-lock.yaml`: there is no new dependency.

- **Step 6.** The caption is the Race's one visible clock label. Each lane clock gets an `aria-label`. The texts are the spec's web table.
- **Windows.** The full run follows `--maxWorkers=4` when load flakes appear. A browser test that fails in a full run is rerun alone before it counts.
