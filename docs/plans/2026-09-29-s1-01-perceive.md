Only step 2 changes `pnpm-lock.yaml`.

Step 1. The fixture numbers are the spec's table, copied exactly. The loader doc comment carries the measuring notes: hand-measured, what is not measured and why, and that `s1-02` replaces the numbers. `index.ts` gets one line, `export * from "./measurement.js";`, between `finding` and `observation`. The file is never rewritten.

Step 2. `band.ts` exports one function over a measured value, a profile threshold (`ContrastThreshold | PixelThreshold`), and a lazy roll `() => number`. It returns `undefined` when the rule passes, otherwise `{ state, rolled? }`. It calls the roll only for a soft cut that fails, and returns `rolled` for every soft failure, below the floor included. `mask.ts` exports `maskName(runSeed, key, name)` and the mask glyph. Neither module imports anything but `@wayford/core`. `index.ts` stays as it is until step 3.

Step 3. The persona fixtures come from `@wayford/core/fixtures`. The V2 box uses two derived measurements:

- the fixture at viewport height 600, which puts "Order archive" below the viewport;
- the fixture scrolled by 50: `scroll.y` 50 and every `bbox.y` minus 50. That puts only the brand link above, not counted.

The monotonicity test loops seed outer and threshold inner, on Vera with `maxElements` and `maxOptions` unset, softness held at hers. It compares each element's state with its state at the previous threshold for the same seed. Lighter sweeps of `fontPx` and `targetPx` follow. `tsconfig.perceive.json` extends the base config with `files: ["src/perceive.ts"]`. The `typecheck` script becomes `tsc -p tsconfig.json && tsc -p tsconfig.perceive.json`.

Step 4. The entry file is read from `package.json` `exports["./perceive"]`. Specifiers come from `import … from`, `export … from`, `import "…"` and `import("…")`, type-only imports included. Relative `.js` specifiers resolve to `.ts` files.

Step 5. 20 warm-up calls, then 100 timed calls, cycling Ada, Milo, Vera and Zoya over run seeds 1 to 100. It prints one line with the average in ms and the 5 ms budget. Exit 0 whatever the number.

The last step is always verification: `pnpm lint`, `pnpm typecheck`, `pnpm test` and every acceptance command in the task file.
