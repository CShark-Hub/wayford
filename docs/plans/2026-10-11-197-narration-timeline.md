# #197 — Run detail and report: the personas' narration from the race: plan

Task: issue #197 (no task file: an issue fix, "Fix #197" on `main`) · Spec: none (S; the issue is the spec)
Status: approved 2026-10-11 (auto)

The issue's acceptance:

1. On run detail, all of a run's narration can be read without stepping through the replay.
2. From the report, each persona's narration is one click away at most.
3. Every narration line links to its step.

And its recommendation: wasted steps (refused answers) listed too, marked as such; the `narration · after the fact` label kept wherever narration is shown; a Jev run says in one line that it writes no narration.

Display only, from what each screen already holds: run detail's `RunResult` and the Report's `Report` (its `backend` and each seed's `runId`). No core, io or Analyst change, no new fetch, endpoint or search param.
