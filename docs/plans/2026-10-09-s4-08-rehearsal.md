## Notes

- **Step 1.** The user places `.env` in the worktree root and confirms `LLM_ACTOR_BACKEND` is unset or `llm`; the agent never reads, copies or tests for it. The stack starts as `env -u PORT pnpm dev` in a background Bash task. Ports 3000, 5173 and 5174 were free on 2026-10-09; if another worktree holds them, io runs on 3100 with a merged Vite config on 5273, as in the memory note on dev servers, and the plan says so.
- **The watch** (spec §4) is a scratchpad `.mjs` run with `node`: it polls `GET /races`, follows the events of every running race's runs, and on the first `actionPlanned` whose `performedAction.type` is `type` kills io's `tsx watch` process tree with `taskkill /T /F`. It logs every run it follows, so step 5 can check it saw each race run.
- **Steps 2 and 3** use the Playwright MCP browser. Screenshots go to `C:/GIT/promptozaury/.playwright-mcp/`, are copied to the scratchpad when kept, and that folder is deleted before any commit.
- **Wall time.** The check is timed by hand, from the click to the goal view. Scout's `recordedAt`, the race's `startedAt` and the report's `analysedAt` give the rest. The drawn report's time is taken when "Open the report" lands.
- **Step 6 to 7.** As in `s1-07`, gate 2 approves the plan through step 6. Each fix is a row added to this table by an amendment the user approves before it is built. No blocking gap under S means no step 7.
- **Who builds.** The session runs every step itself: each needs the live stack, the user's `.env`, and the watch, and a subagent cannot ask the user.
